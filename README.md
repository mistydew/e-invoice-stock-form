# 电子发票 → 元器件入库单 · 批量生成工具

把一堆电子发票（PDF / OFD / 图片 / ZIP）**批量识别**，自动按供货单位汇总，一键填入**元器件（耗材）入库单**并生成可打印的 Excel 文件。纯前端网页应用，可托管到 GitHub Pages 在线使用，也可安装为桌面/手机“应用”。

> 🔒 **隐私**：识别与生成全部在浏览器本地完成，发票文件不会上传到任何服务器。

---

## 功能

- **批量识别发票**：拖入多个 PDF / OFD / 图片 / ZIP 压缩包（或 XLSX·CSV 明细表）一次处理
  - 文本层 PDF（数电票/电子普票）：精确提取，无需联网
  - 扫描件 PDF / 截图照片：自动启用 OCR（首次需联网下载中文识别模型）
  - 京东系发票的**折扣行**自动并入对应明细（净额入库，可关闭）
  - 每行自动提取：开票日期、销售方、项目名称、规格型号、单位、数量、单价、金额、税额、价税合计
  - 自动勾稽校验：行金额+税额 与 票面价税合计核对，不一致会提示
- **逐行核对**：识别结果可在表格中直接修改/删除/补录
- **自动生成入库单**（版式 1:1 复刻既有模板）：
  - 同一供货单位一张入库单，**入库日期取该单位最近一次**
  - 明细行：序号、耗材名称、规格型号、单位、数量、单价（元)、金额（元)
  - 金额 `=数量*单价` 公式；合计 `=SUM(...)` 公式；**人民币大写**（DBNum2 公式）自动生成
  - 入库单号 = `入库日期&2位随机序号`（如 2026091566），公式自动
  - 每张单 12 行明细起（可调），超出自动扩展；无背景色、自动换行
  - 制表（学生1签名）/ 采购（学生2签名）/ 入库验收 签字行齐全
- **两种输出**：单文件多 sheet（`入库单汇总.xlsx`，明细多的单独一张 sheet，其余每 sheet 2 张）或每个供货单位一个文件（打包 zip）
- 可调项：含税/不含税口径、标题文字、名称列表头、验收编号、sheet 命名等

## 使用

1. 打开网站（或本地运行后访问 `http://localhost:8080`）
2. **第 1 步**拖入发票文件（支持多选；ZIP 自动解包；也可“载入示例数据”体验）
3. **第 2 步**逐行核对识别结果（可直接改）
4. **第 3 步**按需调整生成设置
5. **第 4 步**点“生成并下载 Excel”

### 本地运行

无需构建，任何静态服务器即可（ES Module 不能用 file:// 直接打开）：

```bash
# 任选其一，在项目目录下执行
python -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080`。

### 识别说明

| 文件类型 | 方式 | 效果 |
|---|---|---|
| PDF（数电票/电子普票，有文本层） | 版面坐标解析 | 精确，推荐 |
| PDF（扫描件/图片型） | 自动转 OCR | 良好，首次需联网 |
| OFD | 解包文本层解析 | 良好 |
| JPG/PNG 截图、拍照 | OCR | 良好 |
| XLSX / CSV 明细表 | 直接导入 | 精确 |
| ZIP | 自动解包后按上述处理 | — |

- OCR 使用 tesseract 中文模型，首次使用需联网下载（约几十 MB），之后浏览器会缓存。
- 个别票据版式特殊导致识别不全时，界面会给出⚠提示，直接在表格里手改即可。
- 「规格型号」取发票规格栏原值；发票未印规格时留空（可手填，不影响生成）。

## 生成规则（与纸质模板的对应）

| 入库单栏位 | 来源 |
|---|---|
| 供货单位 | 发票销售方名称 |
| 入库日期 | 该供货单位所有发票中**最近**的开票日期（YYYYMMDD） |
| 入库单号 | 入库日期 + 2 位随机序号（Excel 公式自动生成） |
| 耗材名称 | 发票项目名称（保留 `*分类*` 前缀） |
| 规格型号 / 单位 | 发票规格型号 / 单位 |
| 数量 | 发票数量 |
| 单价（元) | 含税：价税合计÷数量（默认）；不含税：金额÷数量 |
| 金额（元) | `=数量*单价` 公式 |
| 合计（含税） | `=SUM(...)` + 人民币大写（公式自动生成） |

## 部署上线（GitHub Pages）

两种方式任选其一：

**方式 A（推荐，自动部署）**：仓库已包含 `.github/workflows/deploy.yml`，推送后在仓库 `Settings → Pages → Build and deployment → Source` 选择 **GitHub Actions** 即可，之后每次 push 自动更新。

**方式 B（分支托管）**：`Settings → Pages → Source` 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`。

上线后地址形如 `https://<你的用户名>.github.io/<仓库名>/`。手机/电脑浏览器打开后可**添加到主屏幕**，像 App 一样使用（PWA，支持离线缓存）。

### 自己发布到 GitHub 的步骤

```bash
git init
git add .
git commit -m "电子发票转元器件入库单 web 工具"
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

> 注意：`.gitignore` 已排除 `发票-工大抬头.zip`、`入库单汇总.xlsx`、`_samples/`、`_dev/` 等**真实发票数据**，不会被上传。如你自己部署，请同样确认不要把发票样本提交到公开仓库。

### 本地构建 exe

```bash
npm install          # 安装 electron / electron-builder（首次需下载运行时）
npm run dist         # 一键产出 dist-win/ 下的 安装版 + 便携版
```

构建脚本（`scripts/build-win.mjs`）流程：打包应用目录 → 用内置 rcedit 注入图标/版本信息 → 打包安装版与便携版。
图标由 `npm run icon` 生成（`electron/icon.ico`）。`electron/rcedit-ia32.exe` 为 MS-PL 许可的开源资源编辑工具。

## 常见问题

- **生成的 Excel 里行高/样式和纸质模板一样吗？** 一样。版式（列宽/字体/边框/合并/公式）与既有《入库单汇总.xlsx》逐格一致（自动化对比 2926 格 0 差异）；行高未固定、开启自动换行，Excel 打开自适应。
- **大写金额怎么来的？** 与模板相同的 Excel 公式（DBNum2）自动生成，同时文件内已写入预览值。
- **想改表头“耗材名称”为“元器件名称”？** 第 3 步“名称列表头”直接改。
- **识别错了怎么办？** 第 2 步表格里直接改，改完再生成。
